# WBS Planner

WBS Planner helps project managers and delivery leads create project work breakdown structures, assign resources, estimate effort, capture weekly or monthly resource hours, review application access, and save Opportunity and Staffing Plan Resource details to Dataverse.

## Users

- Project managers define projects, budgets, WBS scope, and progress expectations.
- Delivery leads manage assignments, workload, dependencies, risks, and hour variance.
- Team members review their assigned work and enter actual hours by period.

## Key workflows

- Build a hierarchical WBS with phases, deliverables, work packages, and tasks.
- Capture Dataverse Opportunity metadata including opportunity name, pursuit lead, architect, clearance level, entry type, duration, dates, and price to win.
- Save Dataverse Staffing Plan Resources for each planned labor category, solution area, location, and resource note row.
- Maintain primary and secondary Resource Skillsets linked to staffing resources, solution areas, and skillset levels.
- Track grid-entered resource hours by staffing plan resource and generated time period in the Resource Hours table.
- Diagnose live access to Opportunity and Staffing Plan Resource tables from the Opportunities page.
- Review allowed and blocked application catalog records from the project control dashboard.
- Review workload, project health, open risks, and reporting summaries.

## Design direction

The app uses a dense industrial productivity aesthetic with a blue-teal palette, compact tables, clear status badges, and spreadsheet-style entry patterns for practical project controls.
